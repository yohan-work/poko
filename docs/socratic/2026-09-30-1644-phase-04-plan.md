## 판단

- 확인됨: app-server stdio protocol은 renderer-facing UI approval request/reply를 구현하는 데 필요한 interface를 문서화한다.
- 추론: `CodexProvider`만 App Server stdio로 이동하면 Agent Core, Poko event model, storage, renderer를 유지하면서 approval semantics를 얻을 수 있다.
- 미확인: 설치된 CLI versions, supported OS sandbox enforcement, selected command/file permission policy, packaged app support.
