## 판단

- `node:sqlite` synchronous queries block Electron main while executing. Keep operations small, indexed, and off the renderer.
- Node documents `node:sqlite` as release candidate in current releases. Pin compatible Node/Electron/Drizzle versions and add runtime smoke tests.
- The app has no GUI automation available in this environment; persistence must be proven with file-backed integration tests and GUI status reported honestly.
